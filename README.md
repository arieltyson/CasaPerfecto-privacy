# CasaPerfecto Privacy Policy & Data Governance

Welcome to the official, open-source repository for `CasaPerfecto`'s privacy policy.

- Read the policy: [arieltyson.github.io/CasaPerfecto-privacy](https://arieltyson.github.io/CasaPerfecto-privacy/)
- The site: [arieltyson.github.io/CasaPerfecto](https://arieltyson.github.io/CasaPerfecto/)
- The source code: [github.com/arieltyson/CasaPerfecto](https://github.com/arieltyson/CasaPerfecto)

## Why is this on GitHub?

Trust is built on transparency. By hosting our privacy policy and data mapping in a public Git repository, we make sure that:

1. **Historical Tracking:** You can read the commit history to see exactly when and how our privacy practices change.
2. **Technical Honesty:** `DATA_MAPPING.md` matches `PRIVACY_POLICY.md`, and both match the source code, which is also public.
3. **Public Accountability:** If the site behaves differently from this policy, anyone can show it and hold us to it.

## What CasaPerfecto does with your data

Nothing leaves your browser. Salary, workplace, preferences and listings are stored in your browser's session storage, or in local storage only if you turn on "Remember on this device". There are no accounts, cookies, analytics or third-party requests. The site's host, GitHub Pages, receives standard request logs (such as IP addresses) under GitHub's own privacy statement.

## Reporting a Privacy Concern

If you find that `CasaPerfecto` handles data in a way that contradicts this policy, or you find a security vulnerability:

1. Open a new **Issue** in this repository.
2. Tag it with the `privacy-violation` or `security` label.
3. Include steps to reproduce, such as a network request captured in your browser's developer tools.
